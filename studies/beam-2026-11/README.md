# BEAM study (2026-11)

**Question.** Does ENGRAM, as shipped, help a small local model (`qwen3.8:27b` under Claude Code)
remember a long conversation it watched, compared with the same model and harness without ENGRAM?

**Status.** Design and tuning. Nothing is scored. The scored run starts only after the pre-registration
is signed and the student reliably uses ENGRAM for its notes.
